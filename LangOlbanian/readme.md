# LangOlbanian — олбанскей йазыг

Добавляет в движок язык «олбанский» (`ol`), он же «йазыг падонкафф»: фонетическое письмо на основе русского (аффтар, превед, фтопку).

Как устроены языковые модули (каталог `resources/lang`, перевод чужих модулей, жизненный цикл) — см. [README репозитория](../readme.md).

## Что внутри

| Путь в модуле | Что это |
|---|---|
| `resources/lang/ol` | переводы интерфейса (серверные + JS), подключаются ядром напрямую |
| `resources/lang/vendor/forum/ol` | перевод модуля Форума (подмешивается, если он установлен) |
| `stubs/flags/ol.svg` | флаг (превед медвед) для переключателя, копируется в `public/assets/flags/ol.svg` |

## Перевод

Переведены **все** языковые файлы на базе `resources/lang/ru` в стиле языка падонкафф — 22 файла, набор ключей полностью совпадает с `ru`, фолбэк не требуется. Родное название языка для переключателя — `'lang' => 'Олбанскей'` (первый ключ `main.php`).
