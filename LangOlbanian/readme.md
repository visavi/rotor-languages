# LangOlbanian — олбанскей йазыг

Добавляет в движок язык «олбанский» (`ol`), он же «йазыг падонкафф»: фонетическое письмо на основе русского (аффтар, превед, фтопку).

Как устроены языковые модули (механизм `publish`, перевод чужих модулей, жизненный цикл) — см. [README репозитория](../readme.md).

## Что внутри

| Источник | Назначение | Что это |
|---|---|---|
| `stubs/lang/ol` | `resources/lang/ol` | переводы интерфейса (серверные + JS) |
| `stubs/flags/ol.svg` | `public/assets/flags/ol.svg` | флаг (превед медвед) для переключателя |
| `stubs/forum/lang/ol` | `modules/Forum/resources/lang/ol` | перевод модуля Форума (подмешивается, если он установлен) |

## Перевод

Переведены **все** языковые файлы на базе `resources/lang/ru` в стиле языка падонкафф — 22 файла, набор ключей полностью совпадает с `ru`, фолбэк не требуется. Родное название языка для переключателя — `'lang' => 'Олбанскей'` (первый ключ `main.php`).
